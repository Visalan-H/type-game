## How to play

1. Open the game on a desktop browser. The Playground doesn't work well on phones.
2. Wait a few seconds. The board appears next to the `// ^?` lines once TypeScript loads.
3. Add `.play("")` to the end of line 4. Put the cursor inside the quotes and press Ctrl+Space. The list only shows legal moves.
4. To undo, delete the last move.

Your moves live in the page URL, so copy it to share your game.

## How it works

The board is a type. Each move is a generic method call that returns a new type, and the `// ^?` comments print the result inline. In tic-tac-toe, TypeScript checks every possible future game before it picks a square.

The code is in [`game/`](game).
