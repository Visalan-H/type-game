Games that run inside TypeScript's type system

  • Tic-tac-toe ticTacToe().play("5").play("1") You are X. TypeScript is O, and it has never lost.

How it works

Each move is a generic method call that returns a new type. The real TypeScript compiler runs in your browser and decides everything. The page only draws what it returns.
